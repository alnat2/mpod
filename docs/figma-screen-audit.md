## 1. Методология и границы применимости

Согласно правилам проекта (`AGENTS.md`, `skills/frontend-implementation/SKILL.md`):
- Разработке и обязательной сверке подлежат исключительно секции Figma, имеющие официальный статус `Ready for Development` (`Ready for dev`).
- Секции `mpod desktop` (`552:1808`), `mpod mobile` (`700:4535`), `mpod mobile components` (`700:4536`) и `for abooks` (`1309:12604`) являются черновыми/рабочими компоновками и не имеют статуса `Ready for dev`.
- Единственной утверждённой компонентной секцией является `mpod components` (`538:933`).
- Для получения актуальных данных дизайна использован официальный Figma MCP сервер (`get_screenshot`, `get_design_context`), исключая устаревшие локальные дампы.
- Сверка выполнена сопоставлением элементов живого холста Figma с кодовой базой и фактическими браузерными скриншотами приложения.

## 2. Покомпонентная сверка и визуальные пары

### 2.1. TopNav (Figma node `372:643` / `573:2529` vs `top-nav.tsx`)

- **Figma (узел `372:643`, Desktop, 1440px с центрированным контейнером 1200px, h=64px):**
  - Слева: `Logo` (`380:347`) с фирменным знаком `mpod` и волнами.
  - Навигационные элементы (`372:664`): пункты строго озаглавлены **`Player`**, **`Podcasts`**, **`Abooks`**, **`Settings`** (активный пункт выделен фоном `bg-secondary` `#f4f4f5` и полужирным начертанием `Inter:Semi_Bold`).
  - Справа: кнопка действия `+ Add` (`372:699`) с иконкой `hugeicons/plus-sign-square`.
  - Ссылка на скриншот узла из Figma MCP: `https://www.figma.com/api/mcp/asset/4a0c29d5-918a-443e-bf13-4a3494297317.png`
- **Фактическая реализация (`frontend/src/components/mpod/top-nav.tsx`):**
  - Пункты меню: `[{ label: "Player", href: "/home" }, { label: "Podcasts", href: "/subscriptions" }, { label: "Abooks", href: "/audiobooks" }, { label: "Settings", href: "/settings" }]`.
  - Кнопка действия: `<Button variant="secondary" onClick={onAdd}><HugeiconsIcon icon={PlusSignSquareIcon} /> Add</Button>`.
  - **Техническое отличие от предыдущей версии отчёта:** код использует не `NavLink` из `react-router-dom`, а связку `<Button asChild variant={isActive ? "secondary" : "ghost"}><Link to={item.href}>{item.label}</Link></Button>`, где `isActive` вычисляется по пропсу `activeItem` (`Player` / `Podcasts` / `Abooks` / `Settings`). Визуальное соответствие токенам высоты (64px), ширины (max-w 1200px), отступов и цветов сохранено на 100%.
